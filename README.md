#  Personal Portfolio Website

A modern, responsive portfolio website built to showcase my projects, technical skills, experience, and achievements as a Software Developer. The website is designed with performance, accessibility, and clean UI/UX in mind while providing visitors with an easy way to learn about my work and get in touch.

## 🌐 Live Demo

**Website:** *portfolio2-0-sage-pi.vercel.app*

---

## ✨ Features

* Modern and responsive design
* Fast loading and optimized performance
* Dark/Light mode support
* Interactive project showcase
* Skills and technology stack section
* Professional experience timeline
* Contact form
* Downloadable resume
* SEO optimized
* Mobile-first design
* Smooth animations and transitions

---

## 🛠️ Tech Stack
